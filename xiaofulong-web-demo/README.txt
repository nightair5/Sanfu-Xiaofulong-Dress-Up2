小福龙搭子世界网页 Demo

使用方式：
1. 双击 index.html 预览基础页面。
2. 如果浏览器因为本地 file:// 安全策略导致部分交互或图片加载异常，可使用 VS Code Live Server 打开整个 xiaofulong-web-demo 文件夹。
3. 部署时上传整个 xiaofulong-web-demo 文件夹即可。

文件结构：
- index.html：静态入口页面。
- assets/_next/：Next.js 静态运行文件，已改为相对路径。
- assets/images/：已压缩转换的 WebP 图片资源。
- assets/icons/：站点图标。
- assets/data/：资源映射与静态演示数据。
- preview.png：桌面宽度预览截图。

说明：
- 图片已统一转换为 WebP。
- AI 生成海报/短视频为 Demo 模拟逻辑，不调用真实 API。
- 动态智能推荐为 mock 数据演示，不连接真实库存、天气、会员或优惠系统。
- 如果图片不显示，请用本地静态服务器打开该文件夹。
